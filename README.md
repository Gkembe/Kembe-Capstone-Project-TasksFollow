# Project: TasksFollow
TasksFollow is a SaaS task and work management application designed to help companies manage projects, assign tasks, track progress, and communicate through comments and messages.
Software as a Service task and work management application. Build to help companies manage their project and assign task to the employees. Build with ASP.NET Core MVC.
